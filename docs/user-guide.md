# 利用ガイド

ブラウザ画面が開いている場合、アプリの起動は完了しています。最初は「通常生成」で短い文章を生成し、再生できることを確認してください。

## 通常生成

文章から音声を作る画面です。

1. 利用可能なモデルを選びます。
2. 読ませる文章を入力します。
3. モデルが必要とする場合だけ参照音声を選びます。
4. 対応モデルでは、詳細設定から話し方や感情を指定します。
5. 「生成する」を押します。

生成後は再生と保存ができます。モデルが対応していない項目は画面に表示されません。

### seed

seedは生成時のランダムな揺らぎを決める数値です。同じモデル、文章、設定、seedを使うと、近い条件で再生成しやすくなります。「生成後にseedを+1」が有効な場合は、生成成功後に次回用の値が1増えます。

### 長文

長い文章は内部で短く分割して生成し、最後に1つのWAVへ結合します。詳細設定で分割の目安と生成前の分割内容を確認できます。

## モデル比較

同じ文章と条件で複数モデルを順番に生成し、横並びで聞き比べる画面です。完了したモデルから再生できます。

参照音声、seed、長文分割設定は、選択した各モデルへ共通条件として渡されます。話し方メモは対応モデルだけに使用されます。参照音声と話し方メモの両方に対応するモデルでは、どちらか一方が必要です。参照音声だけに寄せる場合は話し方メモを空欄にし、両方を指定すると声質と話し方の条件を同時に使います。

## 参照音声

見本の声に寄せる機能を使う場合だけ登録します。すべてのモデルで必要なわけではありません。

「参照音声」には次の2画面があります。

- 新しく登録
- 登録済み音声

### マイクで録音

参照音声名と読む文章を入力し、入力デバイスを選んで録音します。録音内容を確認してから保存します。

### 音声ファイルから登録

wav、mp3、m4a、flac、ogg、aacを選択できます。ファイルを選ぶと登録前に再生と長さを確認できます。

### 動画URLから登録

利用権限を確認した対応動画URLから、3〜10秒の候補と文字起こしを作成します。BGM・伴奏除去を有効にした場合は、元音声と処理後の音声を比較できます。

字幕を取得できない場合は音声認識へ切り替わります。最初の候補が適切でない場合は、表示済みの時間帯を除外して別候補を追加できます。プレイリストと20分を超える動画には対応していません。

### 品質の目安

- 3〜10秒程度
- 1人がはっきり話している
- BGM、反響、ノイズが少ない
- 音声内で実際に話している文章を正確に入力する

保存先は次の通りです。

```text
reference/voices/<voiceId>/voice.wav
reference/voices/<voiceId>/voice.txt
```

本人の同意または適切な利用権限がある音声・動画だけを使用してください。

### 登録済み音声の管理

登録済み音声では、プレビュー、文章修正、登録ID変更、アーカイブ、復元ができます。アーカイブしても音声と文章は削除されませんが、生成画面の選択肢からは外れます。

## RVC変換

TTSで作った音声、手元の音声ファイル、マイク録音の声質をRVCモデルで変換します。

RVCを使うには、同じモデルの `.pth` と `.index` をモデルごとのフォルダーへ配置します。

```text
models/rvc/my_voice/
├── my_voice.pth
└── my_voice.index
```

使用可能な組がない場合、変換フォームの代わりに配置先とモデル作成ガイドが表示されます。配置後に「再読み込み」を押してください。複数モデルがある場合は画面から切り替えられます。

主な調整項目:

- 声の寄せ具合
- 音程シフト
- ピッチ抽出方式
- 声質保護・破綻抑制

## 履歴

通常生成、モデル比較、RVC変換の履歴はブラウザ内に保存されます。

- 保存上限は120件
- 最初は20件を表示
- 「さらに20件表示」で追加表示
- 各生成画面の最近の履歴は直近8件
- 「履歴をすべて削除」で各画面の履歴もまとめて削除

履歴はブラウザのローカルデータです。ブラウザの保存データを削除すると履歴も消えます。

## 次回の起動

リポジトリ直下の `local-tts.bat` をダブルクリックします。初回セットアップを繰り返す必要はありません。不足している環境が検出された場合だけ自動で修復セットアップが実行されます。
