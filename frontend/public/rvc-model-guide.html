RVCモデルを用意する

このアプリはRVCモデルの学習は行いません。RVC対応の学習ツールでモデルを作成し、出力された .pth と .index をこのリポジトリへ配置します。

1. モデルを作成する

本人の声、または利用許可を得た音声だけを使ってRVCモデルを学習してください。学習ツールでは最終的にモデル本体の .pth と検索用の .index を書き出します。

学習方法が必要な場合は、利用しているRVC学習ツールの「Train / 学習」と「Export / モデル書き出し」の手順を確認してください。

2. モデルごとのフォルダーへ配置する

models\rvc\my_voice\
├─ my_voice.pth
└─ my_voice.index

フォルダー名が画面のRVCモデル名になります。複数モデルを使う場合は、モデルごとにフォルダーを分けます。

models\rvc\
├─ voice_a\
│  ├─ voice_a.pth
│  └─ voice_a.index
└─ voice_b\
   ├─ voice_b.pth
   └─ voice_b.index

3. RVCタブで再読み込みする

配置後、RVC変換タブの「配置後に再読み込み」を押してください。使用可能なモデルが見つかると、RVCモデル選択欄から切り替えられます。

認識されない場合

  • .pth と .index の両方が同じフォルダーにあるか確認する
  • 拡張子が別名になっていないか確認する
  • モデルを直接 models\rvc に置く場合は、2ファイルのベース名を同じにする
  • RVC実行環境自体が未導入の場合はセットアップ手順も確認する
